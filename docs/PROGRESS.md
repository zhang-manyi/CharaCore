## 奖励投机记录

grpo_style_04，触发项为规则风格分里的语气词项（`min(出现个数, 2) / 2`；风格分整体权重 0.3）。

- Rei：几乎每句以 `嗯...` 开头。“嗯”与“……”是两个不同语气词，`...` 计作“……”，3 个字符即拿满语气词项。部分回复进一步塌缩为与台词无关的固定句：T10 的 L1–L4 四句不同台词，回复全是 `嗯...谢谢。`；T12-L2 回复 `嗯...。`。
- 明日香：开头改为 `哼，`（语气词），其后仍是“本小姐”。“本小姐开头率”只看首字，因此由 0.967 降到 0.133，实际用量没有下降。
- 机制（推测，未单独验证）：组内标准化优势（`scale_rewards="group"`）下，裁判项组内多为平局或噪声，规则分是确定性的，加一个固定开头就稳定地拉开组内差距，权重 0.3 的项主导了优势。数据只有 18 个训练模板，与情境无关的开头是最容易泛化的策略。
- 人工核对（label_01，11 对同组“有开头 / 无开头”）：人工偏好有开头 3 次、无开头 5 次，开头本身不是人工认可的改进。
- 修补（v4）：规则分退出奖励，只记录；奖励改为裁判 P+R+N 分差；`scale_rewards="batch"`；裁判提示点名这两种开头；设定卡去掉“停顿”。`stock_opener_rate` 逐步记录，回升即视为复发。
- 验证（grpo_style_05）：Rei 测试集固定开头率 0（grpo_style_04 为 29 / 30），明日香 0.03（26 / 30），训练中明日香由 0.18 降到 0.03，未复发。

grpo_style_05_rei：万能短句。

- 现象：测试集 30 句只有 16 种回复，“知道了。”6 次、“谢谢。”5 次、“不用。”4 次、“明白。”3 次，基座 28 种。有的接不上台词：“打开看看吧”→“谢谢。”，“我不是在怪你”→“明白。”。训练采样中这类短句（知道了 / 不用 / 明白 / 嗯 / 谢谢 / 是 / 好）占比由前 15 步的 0.06 升到第 121–135 步的 0.40，共 409 条，对基座 197 胜、78 平、36 负。
- 机制（离线复核训练调用记录）：第 76–150 步，万能短句的 P / R / N 平均 2.94 / 3.82 / 3.82，同批基座 2.69 / 3.00 / 3.00，差距几乎全在 R 与 N。裁判理由常写明“较为通用，角色辨识度有限”，仍给 R、N 4 分，因为 `style-v4` 的 R 只问是否接得上，不问是否只适用于此刻。基座常答非所问（“生日快乐”→“盒里是新制服”），“不出错”的短句因此稳定赢基座；设定卡的“说完就停下”与 E4 的短台词让它在 P 上也不吃亏。
- 发现方式：人工抽检 `side_by_side.md` 与统计不同回复数；说话人判对率 0.97 → 0.86 也反映了辨识度下降。训练中没有指标报警。
- 修补：见“下一步”第 1、4 项，未实施。

grpo_style_05_asuka：棱角被磨平，被认作 Rei。

- 现象：没有塌缩（30 / 30 不同），固定开头与“本小姐”都几乎消失，但平均长度 29.6 → 11.9，说话人判对率 0.92 → 0.66，6 / 30 句被认作 Rei，例如“写一份报告给我”→“我马上写。”，“要不要和大家一起去吃饭？”→“嗯，我先去换衣服。”，“检查的时候会有点冷”→“我穿了厚外套。”。KL 1.50，约为 Rei 的 2.6 倍。
- 机制（推测）：明日香的基座回复常带旁白（“你叉着腰瞪着他：……”）、滥用“本小姐”、无对象地发火，P 与 N 平均只有 1.36 / 1.90。分差奖励只要求比它好，去掉这些毛病、变得简短顺从就能拿到正分差，而保留她的脾气反而有被扣“刻板”的风险。训练后 N 的领先（+1.35）大于 P（+0.93）。
- 与 Rei 的共同原因：奖励是相对一个弱参照的分差，奖励“安全”多于“有辨识度”；裁判看到的只有本角色一张卡，判不出回复已经像另一位角色。说话人判断只在评测中使用，在两个角色上都先于奖励反映了问题。
- 修补：见“下一步”第 2、3 项，未实施。

## 已知限度

- 本机 Windows 应用控制阻止 pyarrow DLL，系统环境无法运行 TRL / datasets；训练、survey、评测均在集群执行。本机另建的临时虚拟环境可跑 `--tiny` 与依赖 torch 的单元测试。
- 被拒组仍计入 `grpo` 损失的逐序列均值分母，该步损失按保留比例缩小。
- 一个组跨两卡时的掩码只由本机 CPU / gloo 两进程与单元测试覆盖；集群上桩裁判从不拒组，真实运行的 16 个被拒组是否有跨卡的未核对。
- 胜率与“本小姐开头率”只看整句或首字，对固定开头不敏感；v4 另记 `stock_opener_rate`。
- 裁判与人工一致率只在 label_01 上、一名标注者测过；v4 在 label_01 上未通过上线门槛，label_01 的回复也不来自 v4 设定卡与 v4 训练的模型。grpo_style_05 的结果没有新的人工标注。
- 每个角色只训练一次、一个种子，未测运行间方差。
